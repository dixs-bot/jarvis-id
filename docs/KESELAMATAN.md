# Panduan Keselamatan

- Cocokkan model dan codename dengan dokumentasi resmi maintainer.
- Verifikasi checksum dari sumber tepercaya.
- Jangan menebak partisi recovery.
- Unlock bootloader biasanya menghapus data.
- Jangan mencoba bypass FRP atau otorisasi vendor.
- Gunakan mode simulasi terlebih dahulu.
- Test otomatis tidak menggantikan pengujian perangkat fisik.
